# Security reporting

This repository currently distributes research documents and a local verification script. It does not operate a hosted service or distribute a BSG solver.

Report ordinary packaging or documentation problems through issues. Do not post credentials, private data, or exploit details that would expose another system. If GitHub private vulnerability reporting is available for this repository, use it for sensitive reports; otherwise use an existing private contact route with the maintainer before sharing sensitive details. No dedicated security mailbox or response-time guarantee is advertised.

Mathematical counterexamples and proof corrections belong in research review issues rather than security advisories. The PDF checksum checks byte identity; it does not certify that a document is safe or that its claims are true.
