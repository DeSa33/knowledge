# Project map

## Identity and authority

`knowledge` is a research-document repository maintained by DeSa33. BSG v4 is its initial collection. The PDF is the authority for manuscript claims; the supporting Markdown files provide navigation and contribution guidance. Repository checks establish packaging integrity only.

## Task routes

| Task | Read first | Authoritative target |
| --- | --- | --- |
| Understand the collection | [README](README.md) | [Manuscript](BroadSematnicGenralzation%28BSG%29.pdf) |
| Review a proof or definition | [Problem index](docs/PROBLEM_INDEX.md) | Exact PDF section and equation |
| Design an experiment | [Evaluation guide](docs/EVALUATION.md) | Frozen contract and new reproducible evidence |
| Update manuscript edition | [Provenance](docs/PROVENANCE.md) | PDF, `SHA256SUMS`, citation, changelog |
| Change documentation | [Documentation map](docs/MAP.md) | Smallest relevant Markdown file |
| Change CI or checks | [Script guide](scripts/README.md) | Verification script and workflow |
| Contribute a result | [Contributing](CONTRIBUTING.md) | Issue or pull request with scoped evidence |

## Boundaries and dependencies

- The manuscript is an imported research artifact, not generated by this repository.
- `SHA256SUMS` identifies its exact bytes. Updating the PDF requires an intentional provenance and checksum update.
- `README.md` routes readers to `docs/`; `docs/` summarizes and points back to the manuscript.
- `.github/workflows/repository-checks.yml` runs `scripts/verify_repository.py` with read-only repository permissions.
- Issue forms request evidence; they do not certify submissions.
- No implementation, dataset, or external execution service is bundled.

## Change discipline

Update the nearest map when files move or responsibilities change. Keep proposed work in the roadmap and completed work in the changelog. Never convert a local or bounded observation into an unqualified general claim. Implementation files were not moved into this initial repository; the only imported research artifact is the renamed PDF.
