## Folder conventions

Use lowercase descriptive slugs for collection directories. Prefer `projects/<project-slug>/` for mixed project material and `papers/<paper-slug>/` for a paper with several artifacts. Use a collection README to explain actual files, status, and reproduction instructions when available. Avoid empty scaffolding and generic files implying nonexistent evidence.

Supporting guides may live under `docs/<collection-slug>/`. Explicit requested file names and existing public paths take precedence over general naming conventions. The BSG PDF therefore remains at the repository root.

## Authority

Original files are authoritative for their contents. Collection guides summarize them and must distinguish editorial guidance from source claims. The catalog routes readers; it does not independently validate a paper, proof, dataset, or implementation.
